# 原型与 PRD 验收清单

## PC 端

启动：

```bash
cd Ai产物文件-pc端
python3 -m http.server 4173
```

浏览器访问 `http://localhost:4173/`，检查：

- 首页和目标页面可打开，无资源 404。
- 导航、筛选、弹窗和主要按钮可操作。
- 作业状态与 PRD 一致。
- 常用桌面宽度下无内容遮挡或横向溢出。
- 浏览器控制台无影响演示的错误。

## 移动端

首次启动或依赖变化后：

```bash
cd Ai产物文件-移动端
npm ci
npm run dev
```

构建检查：

```bash
npm run build
```

检查：

- 重点覆盖 375×812 和 390×844 视口。
- 作业申请可以完成主要演示流程。
- 作业监控信息可以查看。
- 表单键盘、滚动、底部操作区不存在明显遮挡。
- 不要求提供 PC 端全部管理功能。
- 构建成功，控制台无影响演示的错误。

## PRD

启动：

```bash
cd Ai产物文件-prd文档
python3 -m http.server 4174
```

浏览器访问 `http://localhost:4174/安全作业管理_PRD.html`，检查：

- 页面、目录导航、图片和表格正常显示。
- PC 与移动端范围描述准确。
- 业务规则、字段名称、状态名称一致。
- 修改记录包含版本、日期、范围和负责人。
- 待确认问题没有被写成已确定结论。

## Pull Request 最低验收证据

- 已执行的命令及结果。
- 关键页面截图或简短录屏（界面变化时）。
- 验收标准逐项结论。
- 未验证项、已知限制和后续工作。
