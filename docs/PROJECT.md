# 项目章程

## 基本信息

- 项目名称：安全作业管理
- 当前阶段：方案原型
- 计划完成日期：2026-08-28
- 正式 PRD 格式：HTML
- 当前基线：`v2.0.1--product-baseline`
- 业务规则最终决定人：产品负责人（仓库所有者）

## 产品范围

### PC 端

PC 端承担安全作业管理的完整管理与配置场景，具体功能以正式 PRD 和已确认 Issue 为准。

### 移动端

当前仅承诺以下能力：

1. 作业申请。
2. 作业监控查看。

移动端不要求与 PC 端功能或布局完全一致，但相同字段、状态和业务规则的语义必须一致。

## 阶段目标

在 2026-08-28 前形成可评审的方案原型包：

- 一份可浏览的 HTML PRD。
- 一套可运行、可演示的 PC 端原型。
- 一套可运行、可演示的移动端原型，覆盖约定范围。
- PRD、原型和关键决策之间可追溯。

## 协作职责

- 产品负责人：确定优先级、业务规则和最终验收结论。
- 协作者：按 Issue 范围完成方案、原型或评审，并通过 PR 交付。
- Codex：读取仓库规则和事实源后执行明确任务，输出可审查变更，不代替产品负责人决定冲突规则。

同事加入后，应在本文件补充双方姓名或 GitHub 用户名及固定责任域。
